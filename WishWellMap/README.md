# 🌟 WishWellMap

> A full-stack web application designed to help users map out personal goals, track life milestones, collect memories, and visualize their bucket lists.

🔗 **Live Application:** [https://wishwellmap.onrender.com](https://wishwellmap.onrender.com)

---

## 🚀 Key Features

* **User Authentication**: Secure signup, login, and session management.
* **Wish & Goal Tracking**: Create, categorize, and update bucket list items and personal goals.
* **Interactive Dashboard**: Real-time progress tracking, point metrics, and recent memory logs.
* **Admin Management**: Full visibility over user-generated goals and platform activity via Django Admin.

---

## 🛠️ Tech Stack

* **Backend**: Python 3.10, Django 5.2
* **Database**: PostgreSQL (Production on Neon Tech) / SQLite (Local development)
* **Frontend**: HTML5, CSS3, JavaScript, Django Templates
* **Deployment & Hosting**: Render (Gunicorn WSGI server)
* **Static Asset Management**: WhiteNoise
